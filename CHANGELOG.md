# OpenQPEP Suite Changelog — Release Candidate 1.0.0 (`v1.0.0-rc`)

## Release Candidate 1.0.0 (`v1.0.0-rc`) — Clean-Slate Initial Release Candidate Baseline (2026-11-21)
- **Initial Release Candidate Baseline (`v1.0.0-rc`, `OpenQPEP/RC-1.0.0`, branch `rc`):** Unified release across OpenQPEP Core Protocol (`1.0.0-rc`), Calyx QPEP Client (`RC 1.0.0`, `vc225`), Calyx Encrypted Messenger (`RC 1.0.0`, `vc25`), Calyx Encrypted Email (`RC 1.0.0`, `vc9`), Public Key Transparency Directory (`qpepkeys.calyxlabsinc.org`), and Web Servers.
- **Zero Legacy `-pc` or `-beta` Compatibility:** Strictly enforces **Frozen Wire Format v4 (`\x89QPE\x04\x00`)**, **Compact TLV v4.1 (`\x89QPE\x04\x01`)**, and **Mandatory `kdf_version: 3` (`RFC 9106 QPKD-Argon2id + qSponge-512` bound to `"OpenQPEP/RC-1.0.0"`)**. All legacy `-pc` (`\x89QPE\x03\x00`, `\x89QPE\x03\x01`, `kdf_version: 2`) and `-beta` (`\x89QPE\x01\x01`, `\x89QPE\x01\x09`, `\x89QPE\x02\x00`, `kdf_version: 1`) packets and key rings are strictly rejected with `QPEPLegacyProtocolError`.
- **10 Post-Quantum Suites & 10 Deterministic Golden KATs:** Includes all 5 structured Module-LWE + `HGC-448` lattice tiers (`QLX-768`..`QLX-16384`) and all 5 Beyond-LWE suites (`CIF-SQI-512`, `CRT-RSD512`, `CGM-8192`, `CULC-2048`, `CSP-Omega`) verified bit-for-bit across Python, C99/AVX2/NEON `libopenqpep`, Rust `openqpep-core`, Go, and WASM SIMD128 (`@calyxlabs/openqpep-wasm`).
- **Complete Protocol & Application Stack:** `QPEP-KT` Merkle Key Transparency, `QPEP-Ratchet` Double Ratchet, `QPEP-MLS` 256-member TreeKEM groups, `Sphinx-PQ` Sealed Sender, 100 MB `O(1)`-RAM multi-recipient streaming attachments, `BlindSearchVault` zero-knowledge search, `LT-QR` air-gapped fountain codes, `FIDO2-PRF` hardware passkey binding, `DeniableVault`, $t$-of-$n$ `ThresholdKEM`, Tamarin/ProVerif/Cryptol formal verification models, and 79/79 passing unit and adversarial audit tests.
