## Official Release 1.1.0 Permanent Public Baseline

- **100% Official `v1.0.x` Interoperability & Zero Pre-Release Backwards Compatibility:** Official Release `1.1.0` maintains full Wire Format v5/v5.1, Stream v5, and `kdf_version: 4` key-ring interoperability with all Official Stable Public Releases (`v1.0.0`–`v1.0.2`). All pre-release Release Candidate (`-rc`: `\x89QPE\x04\x00`, `\x89QPE\x04\x01`, `kdf_version: 3`), Production Candidate (`-pc`: `\x89QPE\x03\x00`, `\x89QPE\x03\x01`, `kdf_version: 2`), Beta (`-beta`: `\x89QPE\x01\x01`, `\x01\x09`, `\x02\x00`, `kdf_version: 1`), and legacy stream (`\x89QPS\x02\x07`) artifacts are **strictly rejected** with `QPEPLegacyProtocolError`.
- **Official Frozen Wire Format v5 & Compact TLV v5.1:** Every packet emits and verifies `\x89QPE\x05\x00` (canonical), `\x89QPE\x05\x01` (compact binary TLV with duplicate-tag rejection), or `\x89QPS\x05\x00` (streaming AEAD), with mandatory constant-time ASCII armor checksum verification (`={crc}`), zero cleartext identity headers, and 128 MiB decompression-bomb protection.
- **CMT-4 Key-Committing `CC-512` AEAD:** Dual-stream `AES-256-GCM` + `ChaCha20-Poly1305` + 256-bit `qSponge-512` key/nonce/AAD/ciphertext commitment verified in constant time prior to decryption.
- **Mandatory Memory-Hard KDF (`kdf_version: 4`):** RFC 9106 `QPKD-Argon2id + qSponge-512` (retaining immutable `OpenQPEP/1.0.0` domain-separation binding for seamless `v1.0.x` key unlock), mandatory 64-byte structural passphrase witness, hardware-calibrated memory parameters, and optional `FIDO2-PRF` hardware passkey secret mixing.
- **10 Cryptographically Genuine Post-Quantum Suites:**
  - **5 Structured Module-LWE + HGC-448 Suites:** `QLX-768`, `QLX-1024`, `QLX-2048`, `QLX-4096` (default), `QLX-16384` paired with `QVS-65`..`QVS-1024` (with Verify-Before-Emit Fault-Guard).
  - **5 Genuine Beyond-LWE Suites:** `CIF-SQI-512` (exact 511-bit **CSIDH-512** Meyer-Reith supersingular isogeny + SeaSign + `QHS-512`), `CRT-RSD512` (**LRPC / ROLLO-I** rank-metric syndrome decoding over $\mathbb{F}_{2^{127}}[X]/(X^{47}+X^5+1)$ + **UOV** `QMQ-512`), `CGM-8192` (**Classic McEliece / Niederreiter Binary Goppa Patterson** decoding + `QHS-512`), `CULC-2048` (Zero-Ring Plain-LWE + Binary Goppa Patterson), and `CSP-Omega` (5-Family Beyond-LWE Citadel).
- **Hardened Stateful & Privacy Protocols:** `QPEP-Ratchet` (rotating-ephemeral PCS + atomic AEAD-before-commit state), `QPEP-MLS` (256-member TreeKEM with replay protection), `QPEP-AKE` (bidirectional post-quantum mutual auth), `QPEP-KT` (publicly verifiable Ed448 STHs + RFC 9162 Merkle Consistency Proofs), `QVS-Ring` (genuine Module-SIS AOS lattice ring signatures), `DeniableVault` (indistinguishable masked slot headers + Argon2id), `ThresholdKEM` (true zero-reconstruction HJKY proactive share refresh), `Sphinx-PQ` (fixed-size onion frames + post-AEAD replay tracking), `LatticeZKProof` (canonical 12-bit encoding + uniform masking), `BlindSearchVault`, `LT-QR`, `TimeLockCapsule`, and `EncryptedLWWMapCRDT`.
- **5-Language Runtime Conformance:** Python Reference (`1.1.0`), C99/AVX2/NEON (`libopenqpep`, `-Wall -Wextra -Werror`, branchless CBD/NTT, thread-safe const twiddle tables, fixed Android JNI), Rust (`openqpep-core` `1.1.0`, `#![forbid(unsafe_code)]`, branchless constant-time NTT), WASM SIMD128 (`@calyxlabs/openqpep-wasm` `1.1.0` + `qpep_worker.js`), and Go (`go/openqpep` `1.1.0`).
